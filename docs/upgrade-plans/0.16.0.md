## 2. High-Priority Changes

### 2.1 Configuration & API

| Setting | Default | Required (Yes/No) | Description |
|---|---|---|---|
| `NIM_ENABLED` | `false` | No | Enables NIM Model Serving when set to the literal string `"true"`. If left unset, NIM Model Serving stays hidden. |
| `HF_ENABLED` | `false` | No | Enables HF Model Serving. If left unset, HF Model Serving stays hidden. When both flags are false, the whole Model Servings section is hidden and direct navigation redirects to home. |

Why this is High priority: this is not a startup failure, but it is an operational behavior change. Environments that previously relied on Model Servings visibility now need explicit opt-in.

**Helm values.yaml:**

```yaml
env:
  NIM_ENABLED: 'true'
  HF_ENABLED: 'true'
```

Use one or both keys depending on which serving types the environment should expose.
