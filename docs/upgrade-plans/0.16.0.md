## 2. High-Priority Changes

### 2.1 Configuration & API

| #   | Change              | Action     | Details                                                                                                                                                                          |
| --- | ------------------- | ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | `NIM_ENABLED` added | **Review** | Default is `false`. The app treats only the literal string `"true"` as enabled. If left unset, NIM Model Serving stays hidden.                                                   |
| 2   | `HF_ENABLED` added  | **Review** | Default is `false`. If left unset, HF Model Serving stays hidden. When both flags are false, the whole Model Servings section is hidden and direct navigation redirects to home. |

Why this is High priority: this is not a startup failure, but it is an operational behavior change. Environments that previously relied on Model Servings visibility now need explicit opt-in.

**Helm values.yaml:**

```yaml
env:
  NIM_ENABLED: 'true'
  HF_ENABLED: 'true'
```

Use one or both keys depending on which serving types the environment should expose.
