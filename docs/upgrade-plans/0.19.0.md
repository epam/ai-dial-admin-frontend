## 4. Low-Priority / Optional Changes

### 4.1 Configuration & API

| # | Change | Action | Details |
|---|--------|--------|---------|
| 1 | `CODE_APP_EDITOR_URL` added | **Add (optional)** | Editor URL for Code App applications. When an Endpoints application's `endpoint` and `editor_url` both equal this value, it is shown as the `Code App` source type. When unset, the `Code App` source option is hidden. No default. |
| 2 | `ANALYTICS_ENABLED` [Preview] added | **Add (optional)** | Enables the Analytics section (Query Builder + Tables). Default `false`; when disabled the group and its routes are hidden. |
| 3 | `DIAL_ANALYTICS_API_URL` [Preview] added | **Add (optional)** | Host for the DIAL Analytics data-access service. Required only when `ANALYTICS_ENABLED=true`. No default. |
| 4 | `DIAL_QUERY_ASSISTANT_DEPLOYMENT` [Preview] added | **Add (optional)** | Deployment id (e.g. `applications/<bucket>/<app>__<version>`) backing the Query Builder AI view. The AI view shows only when `ANALYTICS_ENABLED=true` **and** this is set; requests route via `DIAL_CORE_API_URL`. When unset, query generation returns "Query assistant is not configured." |

**Helm values.yaml (only if enabling the Analytics preview):**

```yaml

  env:
    ANALYTICS_ENABLED: "true"
    DIAL_ANALYTICS_API_URL: "https://<dial-analytics-host>"
    DIAL_QUERY_ASSISTANT_DEPLOYMENT: "applications/<bucket>/<app>__<version>"
```

**Helm values.yaml (only if exposing the Code App source type):**

```yaml
backend:
  env:
    CODE_APP_EDITOR_URL: "https://<code-app-editor-host>"
```
