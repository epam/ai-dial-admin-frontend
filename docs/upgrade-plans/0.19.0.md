## 2. High-Priority Changes

### 2.1 Configuration & API

| Setting             | Default | Required (Yes/No) | Description                                                                                                                                                                                                                 |
| ------------------- | ------- | ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `DIAL_CORE_API_URL` | unset   | Yes               | DIAL Core API url. Publications and other Core-direct clients (buckets, files, assets, toolset ops, external-service sign-in, query assistant) call DIAL Core directly forwarding the user JWT. These features fail if unset. |

Why this is High priority: this is a new required variable. Environments that previously did not set it will lose Publications and the other Core-direct features until it is configured.

**Helm values.yaml:**

```yaml

  DIAL_CORE_API_URL: 'https://your-dial-core.example.com'
```

## 4. Low-Priority / Optional Changes

### 4.1 Configuration & API

| Setting                           | Default | Required (Yes/No) | Description                                                                                                                                                                                                                                                                  |
| --------------------------------- | ------- | ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `CODE_APP_EDITOR_URL`             | unset   | No                | Editor URL for Code App applications. When an Endpoints application's `endpoint` and `editor_url` both equal this value, it is shown as the `Code App` source type. When unset, the `Code App` source option is hidden.                                                       |
| `ANALYTICS_ENABLED`               | `false` | No                | Preview. Enables the Analytics section (Query Builder + Tables). When disabled, the group and its routes are hidden.                                                                                                                                                          |
| `DIAL_ANALYTICS_API_URL`          | unset   | No                | Preview. Host for the DIAL Analytics data-access service. Required only when `ANALYTICS_ENABLED` is `true`.                                                                                                                                                                   |
| `DIAL_QUERY_ASSISTANT_DEPLOYMENT` | unset   | No                | Preview. Deployment id (e.g. `applications/<bucket>/<app>__<version>`) backing the Query Builder AI view. The AI view shows only when `ANALYTICS_ENABLED` is `true` and this is set; requests route via `DIAL_CORE_API_URL`. When unset, query generation returns an error. |

**Helm values.yaml (only if enabling the Analytics preview):**

```yaml
env:
  ANALYTICS_ENABLED: 'true'
  DIAL_ANALYTICS_API_URL: 'https://your-dial-analytics.example.com'
  DIAL_QUERY_ASSISTANT_DEPLOYMENT: 'applications/<bucket>/<app>__<version>'
```

**Helm values.yaml (only if exposing the Code App source type):**

```yaml
env:
  CODE_APP_EDITOR_URL: 'https://your-code-app-editor.example.com'
```
