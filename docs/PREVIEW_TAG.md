## Preview Tag

The `Preview` tag is used to indicate functionality that is still under development and not yet complete.

### Purpose

This tag should be added to the UI for features that:

- are currently in active development;
- will not be fully completed within a single release;
- may have limited functionality or unstable behavior.

### Usage

The `Preview` tag should be added to:

- menu items;
- tabs;
- collapsible blocks (accordion sections).

Examples of implementation can be found in the Figma design system.

The tag is typically displayed next to the feature name within the UI.

Additionally, the `[Preview]` label must also be included in:

- documentation;
- README files.

### Notes

- It should be clear to users that the feature is still in progress.
- The tag must be removed once development is complete.
